## Errors

1. **The answer disagrees with the tool without saying so (tool misuse).** paid_media_math returned `verdict: "Implied CPA 150.00 is within break-even (205.00, lifetime gross profit); margin per conversion 55.00"`. The answer reports only the warnings and concludes that paid ads are ruled out. The reasoning that 2% click-to-paid is unrealistic for freemium is sound, but the answer should have re-run the tool with a realistic rate (break-even cvr = 3/205 ≈ 1.46%, which should come from the tool) and shown the result.
2. **An input that matches nothing.** `ltvGrossProfit: 205` doesn't match the $215.61 or $284.15 bounded LTV the answer computed one step earlier.
3. **Numbers on an invented CAC.** The "9–10 months" payback is based on a CAC the assistant made up. This happened partly because unit_economics refuses to run without a CAC (see server fix 2).
4. **Small mental arithmetic.** "$100 lifetime plan equals about 6 months of Pro" (6.25 at $16, 5 at $20, and the answer had just pointed out that the price is inconsistent). The figure is minor but wasn't computed with a tool.
5. **A missed inconsistency in the site's own claims.** pricing.astro:263 says "Parameter values aren't included", while the docs say the statistics contain values sampled from columns. The answer raised the homepage "never write" point but missed this sharper contradiction on the pricing page itself.
6. **Correct handling of a broken tool result.** check_ai_crawler_access returned "No robots.txt found: every bot is allowed by default" when the network was blocked. The assistant rightly ignored it. This is a server bug (see fix 3), not an assistant error.
