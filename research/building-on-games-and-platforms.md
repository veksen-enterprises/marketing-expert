# Building on someone else's game or platform (fan tools, companion apps, Discord bots, fitness games)

**Scope.** Products whose value depends on another company's game, data or platform: fan-made companion sites and tools for a publisher's game (item databases, character planners, calculators, Discord bots), and mobile fitness games that turn real movement into game progress. This note adds to `research/community-and-hobby-products.md` (Discord intents, Premium Apps payouts, Blizzard API terms, Riot developer policies, Steam Web API, Patreon and Ko-fi fees) and `research/platform-and-feature-risk.md` (Twitter, Reddit, Facebook access cuts). It does not repeat them; it cites them by number where needed.

**Access (2026-10-06).** Local session with open network. Most primary pages were fetched with a generic browser User-Agent and read as text. Discord Help Center articles were read through the Zendesk article API. Pages that could not be read are marked. Policies in this area change often (Square Enix replaced its FFXIV policy on 16 Sep 2026); re-check the live page before quoting.

## What this means

- **Fan-content policies and API programmes are different permissions.** Fan-content policies (Blizzard FAQ, Microsoft, Epic, Square Enix, Wizards, Mojang) are revocable, non-commercial licences with narrow money exceptions. Some API programmes (Riot) allow commercial products under review; others (Grinding Gear, Blizzard API terms) do not, or close new registrations.
- **The money exceptions differ a lot.** Ads on the fan site: allowed by Wizards, Riot (passive), Mojang (if not harmful); banned by Microsoft (in the item) and Square Enix FFXIV (no exception), and Epic (no commercial objective). Donations: allowed by Microsoft ("optional") and Wizards; not listed by Riot except for streams; Riot explicitly bans Patreon-style paywalls and crowdfunding. Paid tier: only through a licence or an API programme that allows it.
- **App stores add a second check.** Apple 5.2.1/5.2.2 and Google Play's IP policy can reject a companion app that uses game art or data without permission, and Riot bans store apps without a licence or API key. Microsoft bans selling game content in app stores and ads in free apps.
- **Discord adds a third.** Its Monetization Policy bars monetising content tied to others' IP without written permission, and the App Directory bars IP-violating names, descriptions and commands. A fan bot named after the game, sold through Premium Apps, can fail both even if the publisher tolerates it.
- **Takedowns cluster around four triggers**: scraping or unofficial server access (Pokévision 2016), gambling and real-money item flows (Valve 2016), shipping the publisher's assets (Pokémon Essentials 2018), and conflict with the publisher's own plans (Jagex HD 2021). Reversals (OpenIV 2017, Jagex 2021) followed public backlash and ended in written, narrower permissions.
- **Category choice for a fitness game** decides tab, charts and Screen Time grouping (Apple) or games-versus-apps surfaces (Google, one category only). Observed pattern: IP-led location games pick Games; fitness-first studios pick Health & Fitness and add Games as secondary. Games holds about 31% of downloads (vendor estimate), and congestion research says more apps in a category means fewer downloads each.

## Folklore and weak claims

- "Publishers never go after fan sites": the dated cases show they act when a tool scrapes, enables gambling or real-money trades, ships their assets or clashes with their plans. Tolerance is not a licence; every policy read is revocable at will.
- "Donations are always fine": Riot lists no donation exception outside streams, and Square Enix's 2026 FFXIV policy allows no website revenue at all.
- "Using the game's name in your domain is normal": Blizzard bans it; Mojang allows it only if it doesn't look official; Epic only if clearly unofficial.
- "Health & Fitness is less competitive, so it ranks better": no source measured chart difficulty by category for fitness games. The congestion study is about a games-category redesign on Android, not this choice.
- "Overwolf pays creators $300M, so fan apps earn well": that is the platform's own total, with no per-app distribution.
